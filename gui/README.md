# Crunchyroll Downloader GUI

A desktop app for the downloader, built with [Wails v2](https://wails.io), React, TypeScript, Tailwind and shadcn/ui on Base UI. It uses the same `downloader` package as the CLI.

## Development

Requirements: Go, Node.js and the Wails CLI (`go install github.com/wailsapp/wails/v2/cmd/wails@latest`).

```shell
cd gui
wails dev     # live-reloading app
wails build   # build/bin/crdl-gui(.exe)
```

Settings, including the `etp_rt` cookie, are stored in your user config directory (`%AppData%\crunchyroll-downloader\settings.json` on Windows).

Go bindings in `frontend/wailsjs` are regenerated by `wails dev` and `wails build`. Add UI components with `npx shadcn@latest add <name>` from `frontend/`.
